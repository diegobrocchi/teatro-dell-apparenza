PROMPT DI AGGIORNAMENTO — DA USARE IL GIORNO PRIMA DELLA VISITA
(per lo sviluppatore: incollalo in una nuova conversazione allegando lo ZIP del progetto)

Aggiorna la guida “Dieci modi di guardare — Accademia Carrara” (sito statico per GitHub Pages, PWA) allegata come ZIP. La visita è DOMANI. Obiettivo: ogni opera dei dieci percorsi deve risultare esposta secondo il catalogo online del museo, con piano e sala aggiornati; le tappe di ogni percorso devono essere in ordine di sala. L'utente finale non deve vedere note per lo sviluppatore ("da riconfermare", fonti incerte, ecc.).

────────────────────────────────────────
1. DOVE LEGGERE I DATI (esperienza del 27 ottobre 2026)
────────────────────────────────────────
- Fonte principale: la scheda dell'opera sul sito del museo, https://lacarrara.it/opera/<slug>/
  Campi utili: SETTORE/AREA (es. "Esposizione permanente"), PIANO, SALA, NUMERO DI INVENTARIO, la datazione sotto il titolo e, quando c'è, la sezione "Note storiche".
- WebFetch e la shell del container NON riescono a leggere lacarrara.it (URL non in allowlist) e catalogo.beniculturali.it (robots). Funziona invece il BROWSER INTEGRATO sul computer di Diego (strumenti Claude_Browser, sito lacarrara.it già autorizzato): apri una scheda qualsiasi e, da quella pagina, leggi le altre con fetch() same-origin (script pronto al punto 5).
- La ricerca del catalogo (/collezioni-online/?q=...) va in timeout (504): non usarla, usa gli slug della tabella al punto 4. Se uno slug restituisce 404, prova varianti (es. "-2", "-5", "di-una-", apostrofi tolti: "leonello-deste").
- Prestiti e restauri: https://lacarrara.it/opere-in-prestito/ e https://lacarrara.it/opere-in-restauro/ (elenco opere con link /opera/...). Il 27/10/2026 nessuna opera della guida compariva; in prestito c'erano solo carte da tarocco e l'Autoritratto con tavolozza del Piccio. L'elenco potrebbe non mostrare tutto: fa fede il campo SETTORE/AREA della singola scheda.
- Mostre in corso: https://lacarrara.it/en/exhibitions (una mostra può spostare opere). Il 27/10/2026 in programma "Federico Zeri. Un diario personale" dal 12/11/2026 al 04/07/2027: se la visita cade in quel periodo, controlla se coinvolge opere della guida.
- Le pagine evento "Vista da vicino" indicano la sala di una data passata: NON sono una conferma della collocazione attuale.
- Fonte secondaria per la storia: schede SIRBeC su https://www.lombardiabeniculturali.it/opere-arte/schede-complete/C0050-xxxxx/ (raggiungibili con WebFetch solo dopo che l'URL è comparso in una WebSearch). Sono più vecchie: collocazioni del 2008, alcune date e attribuzioni diverse dal museo. In caso di conflitto prevale SEMPRE la scheda del museo.

2. COSA AGGIORNARE IN routes.js (per ogni opera, in tutti i percorsi in cui compare: chiave "key")
────────────────────────────────────────
- room (numero sala), floor, roomLabel = "Piano N · Sala S"
- availability = "Esposizione permanente, piano N, sala S."  (testo mostrato all'utente in "Dove si trova": solo il dato, nessuna avvertenza)
- availabilityChecked = data del controllo
- date = datazione come sulla scheda del museo; museumPage = URL della scheda
- Poi riordina le opere di ogni percorso per sala crescente (a parità di sala mantieni l'ordine esistente).
- Se un'opera NON è esposta (in prestito, in restauro, deposito, scheda senza "Esposizione permanente"): sostituiscila con un'opera esposta coerente con il tema del percorso, con storia presa dalle Note storiche del museo, immagine verificata (punto 3), domanda e brano musicale (italiano o strumentale). Non lasciare in pagina opere non visibili e non mostrare avvisi all'utente.
- Testi "Un po' di storia": solo fatti presenti nelle fonti (prima il museo, poi SIRBeC). Non attribuire a un quadro dettagli di altre versioni (es. finestra e tortora del Giuliano de' Medici sono nella versione di Washington). Se non puoi verificare un dettaglio, toglilo.
- Campo "extra" (sezione "Un dettaglio" della pagina): ogni opera ne ha uno, con kind = dettaglio | tempo | fuori | museo, title, text, sources [[titolo, url], ...] e, per i dettagli visivi, crop {file, ar = larghezza/altezza dell'immagine, x, y, w, h in percentuale}. Se sostituisci un'opera, prepara anche il suo "extra": solo fatti con fonte linkata; per i ritagli verifica a vista nel browser integrato che il riquadro inquadri davvero il particolare.
- Non servono numeri di versione: la pagina rileva da sola i file cambiati e si ricarica (sezione "Aggiornamento automatico" in app.js). Non aggiungere parametri ?v= in index.html. Cambia SW_REVISION in sw.js solo se modifichi sw.js.

3. IMMAGINI
────────────────────────────────────────
- Le immagini sono file di Wikimedia Commons indicati in routes.js (campo image / images). La pagina NON fa ricerche automatiche: se un file non si carica mostra "Immagine non disponibile".
- Commons non è raggiungibile dalla shell del container; verificalo dal browser integrato con fetch a https://commons.wikimedia.org/w/api.php?...&origin=* (prop=imageinfo per controllare che il file esista; list=categorymembers su "Category:15th-century paintings in the Galleria dell’Accademia Carrara (Bergamo)" e simili per cercare; la ricerca list=search a volte risponde "too busy").
- Per essere sicuro che l'immagine sia l'opera giusta, confrontala visivamente con l'immagine della scheda del museo (meta og:image della pagina /opera/...). Attenzione: cercando "Jacobello di Antonello" esce anche una Madonna del Fogg Museum, che è un'altra opera.

5. SCRIPT PER IL BROWSER INTEGRATO (eseguire con javascript_tool su una pagina di lacarrara.it)
────────────────────────────────────────
const slugs = {pisanello:"ritratto-di-leonello-deste",jacopo:"madonna-col-bambino-5",botticelli:"ritratto-di-giuliano-de-medici",girolamo:"san-gerolamo-leva-la-spina-al-leone",lotto:"ritratto-di-lucina-brembati",redetti:"ritratto-di-una-bambina-di-casa-redetti",isotta:"ritratto-di-isotta-brembati-grumelli",spiniB:"ritratto-di-bernardo-spini",spiniP:"ritratto-di-pace-rivola-spini",ceruti:"ritratto-di-fanciulla-con-ventaglio",galgario:"ritratto-di-giovane-pittore",baschenis:"ragazzo-con-canestra-di-pane-e-dolciumi",pellizza:"ricordo-di-un-dolore"};
window.__loc = {};
await Promise.all(Object.entries(slugs).map(async ([k,s]) => {
  try {
    const ctl = new AbortController(); setTimeout(()=>ctl.abort(), 35000);
    const r = await fetch('/opera/'+s+'/', {signal: ctl.signal});
    if (!r.ok) { window.__loc[k] = 'HTTP '+r.status; return; }
    const d = new DOMParser().parseFromString(await r.text(),'text/html');
    d.querySelectorAll('script,style,noscript').forEach(e=>e.remove());
    const lines = d.body.textContent.split('\n').map(x=>x.replace(/\s+/g,' ').trim()).filter(Boolean);
    const L = lines.map(x=>x.toLowerCase());
    const get = n => { const i = L.indexOf(n); return i>=0 ? lines[i+1] : null; };
    const t = L.indexOf('torna ai risultati');
    window.__loc[k] = [lines.slice(t+1,t+4).join(' | '), get('settore/area'), 'piano '+get('piano'), 'sala '+get('sala'), get('numero di inventario')].join(' | ');
  } catch(e) { window.__loc[k] = 'ERR '+e.message; }
}));
window.__loc
(Le richieste in parallelo con timeout evitano che lo strumento scada dopo 45 secondi. Per le note storiche: prendi le righe dopo "Note storiche" fino a "Piazza Giacomo Carrara".)

6. OUTPUT
────────────────────────────────────────
- Mantieni: mobile-first, nessuna sintesi vocale, elenco dei percorsi con miniature, immagini ridimensionate, avanzamento locale per percorso, PWA (manifest, sw.js, icons/), pulsante per l'uso offline.
- Aggiorna VERIFICA_VISITA.txt con data/ora del controllo, fonti, collocazioni trovate, opere sostituite e motivi.
- Controlla la sintassi (node --check app.js sw.js; routes.js deve caricarsi), prova i dieci percorsi e produci un nuovo ZIP completo per GitHub Pages.
- Non dichiarare verificato ciò che non hai letto davvero: se il sito del museo non è raggiungibile, dillo allo sviluppatore (non all'utente) e lascia i dati dell'ultimo controllo.
